# 信息流行病——疫苗犹豫

## 项目简介

麻疹、腮腺炎和风疹联合疫苗（MMR）的安全性争议，在英国引发了持续多年的公共讨论。研究论文、新闻报道、公共卫生机构的回应，以及家长的担忧与选择，共同构成了这段争议的传播过程。

本项目以交互式数据海报呈现 1998—2026 年间英国 MMR 疫苗争议的发展脉络，尝试把分散在不同年份的报道、事件和数据放在同一张图中，帮助读者了解媒体叙事如何变化，以及公共卫生信息如何在社会中传播。

## 展示内容

网页沿时间线梳理争议中的重要阶段，并呈现媒体报道倾向、疫苗接种与麻疹病例相关数据、关键机构和人物，以及家长对疾病风险、医疗机构和疫苗的看法。读者可以切换时间阶段、查看图表和相关资料，沿着时间线探索事件之间的联系。

图表中的并置用于呈现时间背景和传播脉络，帮助读者提出问题；它本身不代表因果关系，也不用于判断个人的接种状态或病例归因。

## 为什么做这个项目

疫苗争议不仅关乎医学证据，也与新闻传播、公众信任和个人决策有关。信息在不同群体间传播时，表达方式和传播环境都会影响人们如何理解风险。

我们希望通过这张可探索的海报，让读者从时间、报道和数据多个角度观察这段历史，理解公共卫生沟通面临的复杂处境，并在面对类似争议时更主动地核对信息、辨别证据。
